# ai/

Claude's working folder for Pixel: design notes, decisions, benchmarks and anything else worth keeping between sessions. Read this first when picking the project back up.

**Working on the UI redesign or the findings tool? Start at [redesign/README.md](redesign/README.md).**

| File | What's in it |
|---|---|
| [plan.md](plan.md) | The full plan and build phases (start here) |
| [design.md](design.md) | Technical notes and gotchas |
| [decisions.md](decisions.md) | Dated log of decisions and the user's stated requirements |
| [open-questions.md](open-questions.md) | Things still undecided, untested, or waiting on the user |
| [benchmarks/](benchmarks/) | Measurements (opencode) and research notes (Incus), with scripts |
| [redesign/](redesign/) | UI redesign handoff: brief, the user's taste, target spec, findings tool spec, data map and build order |
| [mockups/](mockups/) | Clickable HTML mockups, one folder per round (r14 is the reference; earlier rounds kept for history) |

Conventions:
- Dates are absolute (YYYY-MM-DD).
- When a decision changes, add a new entry to `decisions.md` rather than editing the old one; update `design.md` to match.
