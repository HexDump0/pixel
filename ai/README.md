| File | What's in it |
|---|---|
| [plan.md](plan.md) | The full plan and build phases (start here) |
| [design.md](design.md) | Technical notes and gotchas |
| [decisions.md](decisions.md) | Dated log of decisions and the user's stated requirements |
| [open-questions.md](open-questions.md) | Things still undecided, untested, or waiting on the user |
| [benchmarks/](benchmarks/) | Measurements (opencode) and research notes (Incus), with scripts |

Conventions:
- Dates are absolute (YYYY-MM-DD).
- When a decision changes, add a new entry to `decisions.md` rather than editing the old one; update `design.md` to match.
