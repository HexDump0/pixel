Pixel, three directions

Each one is clickable and uses the same fake runs with simulated tool calls streaming in, so you can compare them on the same data. Use the switcher at the bottom of each page to flip between them, or to try light and dark.

Workbench A

Runs are the sidebar, grouped by what they need from you, each with its live tool call. The selected run fills the page.

  • PROGRESS.md first, agents and activity beside it
  • Message box docked at the bottom, like a chat with the run
  • Light, calm, closest to the current Pixel
Open Workbench

Console B

Dark and dense, built for the keyboard. The runs table on top, the selected run in a resizable pane below, every tool call in a live line at the bottom.

  • Fleet numbers as one status bar instead of four chart tiles
  • j/k, / to filter, m to message, a for activity, [ ] for tabs
  • The ctOS touch lives in the data: readouts, the run name resolving in
Open Console

Wall C

Every live run is a tile with its last tool calls scrolling by and its latest finding. Throughput is one stacked band across the top.

  • Answer an agent's question right on its tile
  • A run opens as a sheet over the wall; Esc closes it
  • Each run keeps its own colour, from the band to its tile
Open Wall

What changes in all three

  • One place per runThe side panel and the separate run page showed the same things twice. Now there is one run view with tabs.
  • Controls you can scanThe row of twelve buttons becomes Pause, Stop and a ⋯ menu. Model and API key are values you click to change.
  • Fleet numbers stay smallTokens/s, spend, tokens today and memory shrink to one compact readout. The full charts stay on Stats.
  • What needs you comes firstQuestions, failures and recoveries are sorted to the top and say what happened. You answer questions in place, with 1–3 on the keyboard.
  • PROGRESS.md leadsIt's the first thing in a run, with lines added since you last looked highlighted and a Changes view.
  • Monospace only for dataCommands, paths and numbers stay monospace. Labels and headings go back to normal type, without the spaced-out capitals.
